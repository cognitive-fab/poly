*Cognitive Fab · September 2026 · answers [`review-2026-09-29-blunt.md`](review-2026-09-29-blunt.md) · produces draft v0.2*

Every item was accepted. The table gives the change and where it lives. Section and requirement ids refer to v0.2.

## What the review praised, and how v0.2 keeps it

- **The lowering map** stays the source of truth. The conformance suite is generated from it (03 PT17).
- **Frame derivation and require-before-write by construction** stay. The require rule is now precise (item 7b).
- **The double-charge example** now opens the README, with the witness output.
- **No silent clean and `INCONCLUSIVE` with the bound** are unchanged.
- **Promotion before enforcement** for mined rules is unchanged.

## Conclusion

v0.2 accepts every item. The scope is stated in full, the only falsifiable test comes before the runtime is built, and the three semantic holes are closed: domains, gate snapshots and ledger chaining. The riskiest runtime code, the outbox intent, is now a checked machine written in poly itself.
